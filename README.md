# Code-Causality-in-Liquid-Water-as-a-Hallmark-of-Emergent-Glassy-Dynamics 
Code and inputs supporting the paper: https://arxiv.org/abs/2604.19491

The associated datasets are available at: https://doi.org/10.5281/zenodo.20157242

The code dispatch.sh is the bash script to dispatch and inflate the datasets once thees are downloaded and set in the main directory of this repository.
